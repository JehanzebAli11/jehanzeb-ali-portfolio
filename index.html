2026Valar, a firewall for AI

A self-hosted gateway between a company's apps and any LLM. Sensitive data is redacted or blocked before a prompt leaves the network.

  1. One base URL

    OpenAI-compatible. Apps switch to Valar by changing one URL, with no SDK or code changes.

  2. Reversible redaction

    Values become typed placeholders like [REDACTED:pii.cnic:1] and are restored for the user afterwards. The model never sees them.

  3. Deterministic policies

    Versioned YAML policy packs decide observe, alert, redact or block. No second LLM, so every decision is explainable to compliance.
